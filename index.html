Trước khi bắt đầu

CSS là lớp trang trí, không phải kiến thức mới phải học thuộc.

Note của bạn vẫn là Markdown. CSS chỉ nói cho Obsidian biết: heading nào có màu gì, cỡ chữ ra sao, và khoảng cách thế nào.

Nguyên tắc: bạn dùng AI để viết bản đầu, nhưng bạn vẫn là người chọn nó có dễ đọc và hợp với hệ thống của mình hay không.
Bước 1 · Nhờ AI viết code

Đừng bắt đầu bằng code. Bắt đầu bằng một yêu cầu rõ.

Copy prompt này vào AI. Nếu thích màu khác, chỉ cần thay phần mô tả màu.

Tôi là người mới hoàn toàn với CSS.

Hãy viết cho tôi một CSS snippet để đổi màu H1, H2, H3, H4, H5 và H6 trong Obsidian.

Yêu cầu:
- Phong cách dark studio, nền xanh đậm.
- Heading dễ đọc, có độ tương phản tốt.
- Mỗi cấp heading có một màu khác nhau nhưng vẫn cùng một hệ màu.
- Hỗ trợ cả Reading view và Live Preview.

Giải thích từng phần bằng tiếng Việt.
Chỉ trả về code CSS hoàn chỉnh trong một code block và hướng dẫn tôi dán code vào đâu.
Bước 2 · Nhận code từ AI

Chỉ copy phần CSS, không copy lời giải thích.

AI thường trả lời gồm phần giải thích và một khung code. Bạn chỉ copy nội dung bên trong khung code CSS.

/* Heading colors cho Obsidian */
.cm-header-1,
.markdown-preview-view h1 { color: #f2bd55; }

.cm-header-2,
.markdown-preview-view h2 { color: #e77a66; }

.cm-header-3,
.markdown-preview-view h3 { color: #8ed0ae; }

.cm-header-4,
.markdown-preview-view h4 { color: #a6c7f2; }

.cm-header-5,
.markdown-preview-view h5 { color: #d6b6eb; }

.cm-header-6,
.markdown-preview-view h6 { color: #b9cbc4; }
AI trả code khác cũng không sao. Miễn là nó có selector cho cả `.cm-header-*` và `.markdown-preview-view h*`, để màu hoạt động ở cả lúc viết và lúc đọc.
Bước 3 · Dán vào Obsidian

Tạo một CSS snippet rồi bật nó lên.

1

Mở phần cài đặt

Trong Obsidian, mở Settings, rồi chọn Appearance.

2

Tìm CSS snippets

Kéo xuống phần CSS snippets và bấm biểu tượng thư mục để mở thư mục snippets.

3

Tạo file CSS

Tạo một file mới, ví dụ:

heading-colors.css

Đuôi file bắt buộc là .css, không phải `.txt`.

4

Dán, lưu, bật

Dán CSS vào file, lưu lại, quay về Obsidian và bật công tắc cạnh tên snippet.

Tạo hoặc mở một note có đủ H1, H2, H3. Kiểm tra cả lúc đang viết và lúc chuyển sang Reading view.

Nếu gặp lỗi

Đừng xoá hết. Kiểm tra từng điểm một.

Snippet không xuất hiện

Kiểm tra file có nằm đúng thư mục CSS snippets không và tên file có kết thúc bằng `.css` không.

Không có gì thay đổi

Quay lại Settings → Appearance, tắt rồi bật lại snippet. Nếu cần, đóng và mở lại Obsidian.

Màu bị khó đọc

Nhờ AI: “Hãy tăng độ tương phản, giữ nguyên selector và kiểm tra cả nền sáng lẫn nền tối.”

AI trả cả giải thích vào code

Chỉ copy phần nằm trong code block CSS. Không copy dấu backtick hoặc phần giải thích bên ngoài.

Definition of done

Đến đây là bạn đã làm xong.

  • Bạn có một CSS snippet đang được bật.
  • H1, H2 và H3 có màu có chủ đích.
  • Thay đổi hoạt động trong một note thật.
  • Bạn biết cách nhờ AI chỉnh màu mà không cần làm lại từ đầu.
